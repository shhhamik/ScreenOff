# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-07

Initial public release.

### Added
- Double-tap empty space on the home screen to turn the screen off.
- Double-tap the status bar to turn the screen off (optionally only while the home screen is showing).
- Quick Settings tile that locks the screen.
- Adjustable double-tap time (100 to 600 ms).
- Optional vibration on lock: strength, length, single or double pattern, and a test button.
- Single settings screen with switches and sliders, following the system light/dark and Material You colours.
